# 围棋对局

中国规则，贴目 7.5。可以和 AI 对局，也可以做死活、手筋。

在线地址（电脑关机也能打开）：https://moshujiqiao39.github.io/weiqi/

在线页在浏览器里运行自对弈模型。18 级到 9 段的 KataGo 人类棋力模型只在本机程序里。

自对弈会改这个小模型的权重：本机写在 `models/rl_policy.json`，在线页写在这台浏览器里。它会少下一些明显的错棋，但不会因此变成 9 段。KataGo 的段位模型是固定的，这些对局不会让它变强。

## 打开

双击 `启动围棋.bat`，或在这个文件夹里运行：

```
py -3 run.py
```

浏览器会打开本地页面。关掉那个黑窗口，网站就停了。

## 两种引擎

- **按段位**：用 KataGo 的人类棋力模型。18 级到 9 段各有一档，低段按该级别棋手的着法分布走，段位越高越少下明显的坏棋，思考也更久。普通电脑上每步大约几秒，不是职业超算棋力。
- **自对弈**：项目里的强化学习引擎。它用局部特征选点，下完 9 路自对弈后按胜负改权重。页面上的「训练」会累积这些权重。

模型文件已经在 `models` 里。第一次打开网站时，KataGo 加载模型要大约一分钟。

## 训练更多局

页面里可以训练 10 局。也可以：

```
py -3 -c "from go_site.ai import play_training_game; play_training_game()"
```
